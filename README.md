# Abdelghafour Nimhil (Abdo) - Portfolio

Creative Portfolio & Folio built with React, Vite, GSAP, WebGL Shaders, and smooth Lenis scrolling.

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

## 🛠️ Tech Stack
- **Framework**: React + Vite
- **Animations**: GSAP (GreenSock)
- **Shaders**: WebGL (Custom 4D Simplex Noise Transition Curtain)
- **Smooth Scroll**: Lenis
- **Audio**: Custom Audio Player with Auto-Ducking
